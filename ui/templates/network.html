自动识别的边界

  1. 订阅选择「自动识别」

    绑定固定网络环境的订阅继续使用指定配置。自动识别不再套用默认环境。

  2. 请求只能证明当前使用的协议

    IPv4 请求不代表设备没有 IPv6，反之亦然。确认双栈后，可通过网段绑定或固定环境放行两类线路。

  3. IP 归属不能证明专网可达

    自动识别默认排除 IPTV 专网；需通过环境档案明确配置。VPN、代理和移动网络可能影响归属准确性。

  4. 真实 IP 由 Cloudflare 提供

    云端只信任平台注入的客户端信息，不接受访问者自行提交的运营商、地区或 X-Forwarded-For。
